# B07 合成授权检索验收记录

日期：2026-09-14。任务：B07；契约：冻结 v2.0.0；代码为当前未提交工作区。数据为临时 PostgreSQL 17 与固定合成租户/主体/仓库，Git 和证据使用测试私有目录。无模型调用、真实来源或真实身份接入。

## 实现与预期结果

- 新增加法迁移 006、最小 API/Worker grants、主体小时读窗口与无正文成本记录；001—005 历史迁移未重写。任务首次 search 绑定不可变环境，同主体/仓库存续 client_session_id 复用，不重置预算。
- search/get 共用任务默认 3 次预算；主体固定小时最多 20 次、滚动小时最多 10 个新会话。短事务预留，读取在事务外，最终事务重新验证授权和状态并扣减。operation_id 重传返回原逻辑结果、不重复扣减；载荷冲突拒绝，generation/租约隔离过期执行者。
- 中文 NFKC/Intl.Segmenter 分词和精确 API、错误码、路径标识符；PostgreSQL simple 加权关键词检索，标题/结论/条件权重为 4/2/1。先过滤已授权范围，再从当前 Git 正文核验版本、条件和引用。未知依赖要求澄清，已知不兼容结果跳过；不猜测复杂范围或预发行版本。
- 默认最多 5 条、4000 个预算单位，客户端不能提高服务端上限。TokenCounter 当前采用 UTF-8 字节作为保守单位，版本 utf8-bytes-v1，不是模型 BPE。计数针对语义正文/元数据，不是完整网络信封。完整条件、排除项、依据和引用不可静默裁切；装不下返回 clarification_required 或 budget_limited 元数据。
- 无答案、条件澄清和正常受限结果消耗一次读取；技术故障释放预留。pending/failed 索引为暂不可用，不能用空数组伪装零答案。撤权、暂停、撤回、旧当前版本或证据不可读阻止正文及缓存重传；历史读取另需 history 授权且条目仍在服务。
- 发布/生命周期事务排队 search_index；独立 Worker 使用租约、owner/generation 和三次重试，Git 读取在事务外，提交前检查当前目标。索引版本 zh-segmenter-exact-v1，可移除失效条目并显式重建。重建将当前 publication.index_status 置 pending，失败不会撤销已发布正文，恢复后变 ready。只投递索引相关 published/suspend/withdraw/archive outbox。
- 默认 MCP 无权限；AKB_SYNTHETIC_TOOLS=1 才允许无凭据、无跳转的 loopback HTTP，15 秒超时。search-knowledge、get-knowledge、get-contribution 经共享 SDK 访问真实 API 并校验输出/structuredContent；其他五个工具无业务副作用。冻结错误枚举使用 TEMPORARILY_UNAVAILABLE，消息 CAPABILITY_NOT_READY。
