# Web 知识列表、详情与检索

日期：2026-09-14。范围为现有知识 API 的 Web 纵向切片，B10 治理开发暂未开始。

## 接通范围

- `#knowledge`：真实授权知识列表、签名游标分页、刷新、加载、空结果和错误状态。只列出当前已发布且启用的知识；在同一授权事务中核对 Git 正文及证据可读性，返回前再次核对状态。
- `#knowledge/<id>`：完整正文、适用前提、例外、依赖、原因、失效条件、知识增量及证据版本和定位。读取管理详情不占任务预算。
- `#search`：实际创建任务、提交问题和环境、展示适用结果及澄清问题、剩余额度；展开调用任务绑定的 `readKnowledge`，不绕过预算读取管理详情。
- HTTP 失败不能伪装成无适用知识；失败重试使用原请求操作 ID。浏览器会话按身份和仓库复用任务，重复创建不会补充同一任务额度。
- 切换页面回到顶部，知识查询返回页面时重新核对，刷新期间不展示旧缓存正文；身份变化重建查询缓存及页面状态。

## 验证

`pnpm verify` 验证契约、构建、类型、lint、常规测试和格式。新增真实数据库测试覆盖知识列表分页、主体绑定游标、证据授权撤回、暂停排除及列表不占任务预算。`pnpm test:database` 共 76 项全部通过，迁移 001–008 无新增变更。

本地合成开发库使用真实服务冻结证据、由两个固定独立合成主体完成判定与审核，再由 Worker 异步发布到 Git 并生成检索索引。两条示例的标题和正文明确标识合成边界。

浏览器实测列表显示两条已发布示例，标题跳转详情、详情进入检索；“人工审核”命中，`zzunmatchedrocket` 无适用知识。同一浏览器任务三次读取后额度耗尽，热更新再次检索仍保留服务端额度。独立浏览器任务检索后展开完整详情，实际计数从 1/3 增为 2/3，显示完整原因、增量与证据定位。

## 边界

本次只完成知识浏览和检索页面，不代表贡献、审核、验证、配置治理管理表单全部完成，也不代表 S0/S1 或生产验收。默认参数为本地合成仓库；实际依赖和人工适用前提需要使用者确认。现有检索是分词关键词匹配，长问题中的常用词可产生较宽结果，未引入语义模型或排序升级。证据展示为引用定位，未增加证据内容浏览器。页面数据在读取或刷新时核对，未实现状态变更推送。
